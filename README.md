# Textree (Web Treemap Prototype)

사용자가 첫 페이지에서 단어를 입력하면:

1. 트리맵(Treemap)에서 해당 단어 노드가 **반짝이며 강조**되고,
2. 노드를 클릭하면 해당 단어의 **체계 경로(상위~하위), 주변 단어 환경**이 보이며,
3. 외부 **백과/사전 API 연동**으로 추가 설명을 가져옵니다.

## 실행 방법

```bash
python3 app.py --port 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 구현된 핵심 기능

- 단어 검색 UI (첫 화면 진입 즉시 사용 가능)
- 계층형 지식 그래프를 Treemap으로 시각화
- 검색 단어 노드 반짝임 강조(blink)
- 노드 클릭 시 주변 단어 정보 표시
  - 설명
  - 체계 경로
  - 하위 개념
  - 연관 단어
- 외부 데이터 연동
  - Wikipedia summary API (zh/en)
  - DictionaryAPI (영문 의미)

## 데이터 소스에 대한 참고

요청하신 “백과/사전의 모든 단어 DB”는 실제로는 매우 큰 데이터셋(수백만 엔트리)과 라이선스 검토가 필요합니다.
현재 프로토타입은 아래 방식으로 확장 가능하도록 만들었습니다.

- 내부: `knowledge_base.json` (서비스 고유 분류체계)
- 외부: 공개 API 실시간 조회 (백과/사전)

원하시면 다음 단계로는 오프라인 대규모 사전 dump(Wiktionary/WordNet 등) 기반 인덱스 서버를 붙일 수 있습니다.
