# Textree（词语全局视图 MVP）

这个小程序实现了你描述的核心能力：

- 用户输入一个词语（如 `妈妈`、`看`）
- 程序立刻展示这个词在“世界 -> 大类 -> 子类 -> 词语”中的位置
- 同时展示它的定义、下位概念、相关词，帮助用户从大局看单词

## 运行方式

```bash
python3 app.py 妈妈
python3 app.py 看
```

## 示例输出

```text
⚡ 词语：妈妈
类型：word
定义：母亲的常见称呼，强调亲属关系中的照护角色
全局路径：世界 > 人类 > 关系 > 家庭关系 > 妈妈
下位概念：无
相关词：爸爸、孩子
```

## 数据结构

知识库保存在 `knowledge_base.json`，每个节点包含：

- `type`: 节点类型（`root`/`category`/`word`）
- `description`: 描述
- `parent`: 父节点
- `children`: 子节点
- `related`: 相关词（可选）

你可以继续扩充这个 JSON，把更多词语纳入统一体系中。
